# Ciallo DS4F Proxy

来都来了 不点个⭐再走吗~?

把 [opencode zen](https://opencode.ai) 的免费模型包成一个本地网关,同时支持 **OpenAI** 和 **Anthropic** 两种协议。

出口走你自己的机场节点(内置 mihomo 解析订阅),撞到 429 自动换下一个节点 —— 因为免费额度是**按出口 IP 计**的,换 IP 就等于换额度池。
